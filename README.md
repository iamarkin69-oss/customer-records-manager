# Customer Records Manager

Программа для записи и обработки клиентов в JSON файл

## Возможности

- Добалвение новых клинтов
- Удаление клиентов
- Обновление данных клиента
- Вывод списка клиентов
- Вывод отсортированных клиентов по городам
- Поиск клиента по ID

## Запуск

python main.py

## Примеры использования

Запуск -> Выбор функции -> Ввод необходимых данных -> Получение результата -> Новое действие / Выход

## Ограничения

При ручной обработке JSON файла, программа может перестать работать из-за нарушения структуры написания файла. Работать с файлом необходимо исключительно в программе
